# 기한 신호 설계 (신입 "지금 할 일" 보강 · 부서 업무함 "기한 초과" 탭)

작성일: 2026-11-27 · 상태: 방향은 Leo가 대화에서 정함, 시안 Leo 확인 대기. 구현 계획: `docs/superpowers/plans/2026-11-27-due-signals.md`

## 1. 의도

SuccessFactors·Workday 온보딩 조사에서 두 제품이 앞선 곳은 운영 관리, 특히 기한 초과를 바로 보여 주는 대시보드였다(SF Onboarding 대시보드는 기한이 지나는 즉시 "기한 초과"로 바꾸고 업무 대기열을 Excel로 내보낸다). 1차 심사 기간이라 작고 시연 효과가 큰 두 가지만 넣는다.

- 신입: 무엇이 급한지 한눈에 본다. "지금 할 일" 카드는 이미 있으므로(보완 요청 → 기한 이른 순, 5건) 새 카드를 만들지 않고 기한 표시를 보강한다.
- 경영지원 담당자: 기한이 지난 과제와 오래 기다린 확인 대기를 찾고, 목록을 Excel이나 CSV로 내려받는다. 새 화면이 아니라 S9 부서 업무함의 탭으로 둔다.

## 2. 목표 / 비목표 / 실패 조건

**목표**
1. S2 과제 행(신입이 할 차례인 과제만): 지남 / 오늘 마감 / D-N(7일 이내) 표시. 인사 문구에 "기한 지남 K건".
2. S9 "기한 초과" 탭: 끝나지 않고 기한이 지난 우리 부서 과제, 차례(신입·담당자·선행 과제 대기)와 지난 일수.
3. S9 확인 대기 줄에 "N일 대기", 요약 카드 "기한 초과".
4. S9 "Excel 내려받기"·"CSV 내려받기": 지금 탭의 지금 행.

**비목표**: 알림·메일, 서버 집계·RPC·마이그레이션, 새 경로·메뉴, 일괄 처리, 상태 이력, 드롭다운 메뉴 컴포넌트 추가.

**실패 조건**: 같은 과제를 신입 화면과 담당자 화면이 서로 다른 날로 "지남" 판정한다(시간대 불일치). 다른 부서 과제가 기한 초과 탭·개수·내려받기 파일에 섞인다. 내려받은 파일에서 `=`로 시작하는 값이 수식으로 실행된다. 기존 탭 4개의 동작이 바뀐다.

## 3. 접근 방식

| 방식 | 내용 | 장단점 |
|---|---|---|
| **A. 기존 화면 보강 (선택)** | S2 카드의 기한 표기 보강, S9에 탭 하나 | 데이터·컴포넌트가 이미 있다. 새 메뉴·시안이 필요 없다 |
| B. 새 "오늘 할 일" 카드 + 별도 보드 `/ops/board` | 카드 하나 더, 새 화면 | 같은 과제가 두 카드에 겹치고 화면·메뉴·시안이 는다 |

Leo가 A를 골랐다(S2 "기존 카드 보강", S9 "기한 초과 탭 추가"). 내려받기 형식은 Leo 요청으로 Excel·CSV 중 고른다.

## 4. 정한 것

- 오늘 날짜는 신입·담당자 화면 모두 서울 날짜(`todaySeoul`)로 판단한다. 지금 신입 화면은 브라우저 날짜를 써서 담당자 화면과 어긋날 수 있었다.
- S2 기한 표기: 지남·오늘 마감은 `--st-rework-fg` 굵게, D-N은 muted·`tabular-nums`, 8일 이상 남으면 날짜만. 확인 대기·담당자 처리·잠김 과제에는 붙이지 않는다(지금 "지남" 규칙과 같다). 정렬과 5건 제한은 그대로.
- S9 탭 순서 `확인 대기 · 기한 초과 · 내가 처리할 일 · 입사자별 · 전체`, 기본 탭은 확인 대기.
- 기한 초과 대상: `done`·`na`가 아니고 `due_date < 오늘`(blocked 포함). 기한 오름차순, 같으면 입사자 이름순. 열은 입사자·과제·상태·차례·기한(`11/20 · 7일 지남`).
- 차례: blocked → 선행 과제 대기, submitted 또는 staff_only → 담당자, 나머지 → 신입.
- 확인 대기 대기 일수: `status === 'submitted'`일 때만(보완 요청은 `submitted_at`이 남아 있어 제외), 1일 이상만, 3일 이상은 `text-destructive` 굵게.
- 요약 카드 4개(확인 대기·보완 요청 중·진행 중 입사자·기한 초과), 격자 `md:grid-cols-2 xl:grid-cols-4`.
- 내려받기: 페이지 머리 오른쪽 outline 버튼 둘. 입사자별 탭에서는 숨기고, 행이 없으면 비활성. 열은 입사자·팀·과제·상태·차례·제출 시각·기한·지난 일수(메일 없음). 파일명 `업무함-{부서}-{탭}-{YYYYMMDD}.xlsx|csv`. Excel은 `write-excel-file`을 버튼을 누를 때만 불러오고 모든 칸을 문자열로, CSV는 BOM과 수식 시작 글자 앞 `'`. Excel 파일을 만들지 못하면 "파일을 만들지 못했어요. 다시 시도해 주세요."
