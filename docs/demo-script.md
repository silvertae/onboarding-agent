# 시연 스크립트

`docs/screens.md`의 "시연 흐름"을 단계별 기대 결과와 함께 적은 문서입니다. 스테이징 리허설과 운영 재확인(Task 19 Step 2·5)에 같은 순서로 씁니다.

- 브라우저 창 두 개를 띄웁니다. **창 A**는 신입, **창 B**는 담당자·관리자용이며, 창 B는 시크릿 창으로 열어 세션을 나눕니다.
- 계정 메일은 `docs/judge-guide.md`에 있고, 비밀번호는 별도로 전달합니다. 이 문서에는 비밀번호를 적지 않습니다.
- 시작 전 관리자 화면에서 "데모 데이터 초기화"를 한 번 실행해 시드 상태로 맞춥니다.

### 스테이징 리허설 메모 (2026-11-17, `0b466f9`)

조율 세션이 헤드리스 브라우저(창 A·B를 별도 프로필로)로 위 0~5단계를 실행했습니다. 비밀번호는 스테이징 Secret Manager에서 읽고 기록하지 않았습니다.

- 0: 데모 초기화 → "데모 데이터를 초기화했어요." / 신입 등록 → "계정을 만들었어요…", 표에 "새로 만듦"·기본 계정 "아니요" / 같은 메일 → "이미 등록된 메일이에요" / 새 계정 로그인 → `/me`, `0 / 31`
- 1·2: 잠긴 과제에 "○○ 완료 후 열림 · 선행 과제 대기" / 명함 신청 제출 → 총무 업무함 "확인 대기 1" → "확인 (완료 처리)" → 신입 화면이 새로고침 없이 "명함 신청 완료", `1 / 31`
- 3: 노트북 경비 → 소모품비(가상 기준)로 답하고 "근거"에 해당 지식 / 동호회 가입비 → "확인되지 않은 내용이에요." + "담당자에게 등록 요청" 버튼, 요청 전 미답변 0건·요청 후 1건 (첫 응답까지 약 10초)
- 4: 미답변 1건 → "게시" 후 0건 → 신입 재질문에 등록한 답으로 답하고 "근거"에 그 지식
- 5: 초안 생성 약 20초, "AI가 만든 답안은 확정 전 검토가 필요합니다" 표시 / 문항 하나 "새 문항 만들기" 후 나머지 유지 / 시험지에 답안·채점 기준 없음, 답안지에 있음 / AI-10 "통과" 저장 → 신입 화면 새로고침 없이 반영
- 발견: 모델이 문항·답안에 마크다운 코드 블록 표시(```)를 넣어 화면·인쇄물에 그대로 보이는 경우가 있었음 → PR #22에서 지시문 규칙과 결과 정리로 수정
